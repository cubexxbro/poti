A high-performance hacker tool designed for rapid network asset lookup, banner grabbing, and active IP monitoring—inspired by Shodan.

> [!WARNING]
> **Disclaimer:** Please read the legal notice above before proceeding.

## ✨ Features

* ⚡ **Stateless Syn Scanning:** Blazing fast port discovery across extensive IP ranges.
* 🔍 **Deep Banner Grabbing:** Intelligent protocol handshakes to extract service fingerprints (HTTP, SSH, FTP, etc.).
* 📊 **Cyberpunk Dashboard:** An elegant, dark-themed UI for real-time asset tracking and monitoring.
* 🔔 **Instant Alerts:** Webhook notifications whenever an unexpected port opens or a service changes.
